# Welcome

This is your **Worldbuilder Canon vault** — an Obsidian folder set up to track
the world you're building and the stories you're telling in it.

Everything in here is just markdown files. Nothing is hidden in a database
you can't read. You always own your words.

## What's in this vault right now

The starter content is a tiny example world to show you the file formats.
**Delete it whenever you're ready** — none of it is load-bearing.

- `entities/people/[[Lyra Vance]]` — example character sheet
- `entities/places/[[Brackwater]]` — example place sheet
- `systems/[[Stillweaving]]` — example magic system
- `naming/coastal` — example naming sheet (a list of names you've used or
  considered for one culture)
- `canon/ch01_arrival` — example finished prose chapter
- `brainstorm/2026-05-22-1500` — example brainstorm note

Open any of those to see the format. Don't worry about memorizing it —
**`Canon: New entity`** and **`Canon: Log brainstorm`** in the command
palette create new files for you with the right shape.

---

## What's NOT in this vault

- Drafts. The `drafts/` folder is empty — that's where chapters live while
  you're still working on them. Move a draft into `canon/` when it's settled.
- Anything personal. Replace this example world with yours.

---

## When something feels off

If the status indicator at the bottom-right of the Obsidian window says
**"Canon: sidecar down"** (red), the background program isn't running.
See the troubleshooting section of INSTALL.md (came with the install).

If you're stuck on something Adam (the person who set this up for you)
didn't anticipate — just text him. Worst case: he can read these same
example files and answer faster than you'd find it yourself.
