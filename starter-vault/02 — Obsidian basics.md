# Obsidian basics

Obsidian has hundreds of features. You only need five of them.

---

## 1. The command palette — `Ctrl+P`

Press it. A search box opens. Type a word. Every command in Obsidian
(and every plugin command) is searchable here.

- Type "canon" → see every Worldbuilder Canon command
- Type "new file" → create a new markdown note
- Type "open" → switch between open notes

**You will use this constantly.** Most of Worldbuilder Canon's features
live here, not in the toolbar.

---

## 2. Wikilinks — `[[Name]]`

Type two square brackets. A dropdown appears suggesting notes you could
link to. Pick one (or type a new name and press Enter).

In your prose:

```
Lyra knelt by the [[Brackwater]] harbor and looked east.
```

Two things happen automatically:
- Brackwater becomes a clickable link in reading mode.
- If a note called "Brackwater" doesn't exist yet, the link is dimmer.
  Click it and Obsidian creates the note for you.

**Wikilinks are how Worldbuilder Canon tracks who/what is in each scene.**
If you don't wikilink mentions of your characters, the plugin can't help
you find them later.

---

## 3. The file explorer (left sidebar)

Toggle with `Ctrl+Shift+E`. Shows the folder tree of your vault.

Drag and drop to move files between folders. This is how you promote a
draft to canon: drag `drafts/ch07.md` onto `canon/`.

---

## 4. Search — `Ctrl+Shift+F`

Searches all of your text. Different from Worldbuilder Canon's
`Canon: Search`, which is fuzzy and concept-aware.

| If you want… | Use… |
|--------------|------|
| Exact phrase, fast | Obsidian search (`Ctrl+Shift+F`) |
| "Anywhere I mentioned the lighthouse idea" | `Canon: Search` |
| "What facts do I have about Lyra?" | `Canon: Open pane`, click Lyra |
| "What did I write about magic in chapter 3?" | `Canon: Ask about my world` |

---

## 5. Hot reload — toggle plugins after changes

When Adam ships you an updated plugin, you toggle the **Worldbuilder
Canon** plugin off and on in Settings → Community plugins. That reloads
it without restarting Obsidian.

---

## What you can ignore (for now)

Obsidian has a graph view, daily notes, canvases, templates, embeds,
custom CSS, mobile sync, themes, hundreds of community plugins. They're
all useful eventually. None of them are needed to use Worldbuilder
Canon.

Come back to them when your world has 50+ entities and you start
wanting to see relationships visually.
