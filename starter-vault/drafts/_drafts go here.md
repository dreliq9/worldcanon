# Drafts

Chapters and scenes you're still working on live here.

When a draft is settled, drag it from this folder into `canon/`. That's
the only "promotion" — there's no special button or status to change.

You can delete this note once you have real drafts.

---

## Tip

Filename convention matters less than you'd think. Use whatever helps
**you** find files later. Some patterns that work:

- `ch07_lyra_returns.md`
- `2026-05-22_dock_scene.md`
- `act2_climax_attempt3.md`

The plugin treats every file under `drafts/` the same. Pick a naming
style and stick with it.
